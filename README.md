# Churn-Analysis-Customer-Intrlligence
📌 Overview
This project analyzes customer churn in the OTT industry (Netflix, Hotstar, Prime) using a multi‑dimensional dataset of demographics, subscription tiers, and support escalations. The goal is to identify high‑risk subscribers and provide actionable insights that drive retention and profitability.

🚀 Business Challenge
In the hyper‑competitive OTT landscape, retention is the only way to survive. Acquiring new users is costly, while churn directly impacts profitability. This project demonstrates how data analytics and business intelligence can uncover churn drivers and guide billion‑dollar decisions.

🛠️ Tech Stack
SQL & Python Integration: sqlite3, pandas, numpy

Data Engineering: Cleaning, feature engineering, churn flagging, tenure calculation

Visualization: matplotlib, seaborn for churn trends and behavioral insights

Business Intelligence: Translating technical findings into executive‑level recommendations

📈 Project Milestones
Relational Data Extraction

Connected Python to SQL databases.

Pulled multi‑table datasets (Customers, Subscriptions, Support Tickets).

Advanced Feature Engineering

Calculated tenure, churn rates, and customer aging.

Derived churn flags and segmented customers by subscription tier.

Executive Reporting

Built churn prediction models (Logistic Regression, Decision Trees).

Visualized churn drivers and CLTV distribution.

Delivered BI dashboards highlighting churn trends and retention strategies.

🔍 Key Insights
High churn among basic tier users.

Escalation frequency strongly correlated with churn.

Premium tier customers show higher CLTV and lower churn.

Top 20% of customers contribute ~70% of revenue.

💡 Business Recommendations
Personalized onboarding for new subscribers.

Loyalty rewards for high CLTV customers.

Predictive alerts for at‑risk customers.

Faster support resolution to reduce churn linked to escalations.
